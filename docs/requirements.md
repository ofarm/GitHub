# docs/requirements.md — 要件定義

## 1. ユースケース

- **UC-1 ログイン**: 自分（許可メール）が OAuth でログインする。許可外メールは利用不可。
- **UC-2 リアルタイム翻訳（字幕メイン）**: 英語の音声（主に会議）を PC/iPhone のマイクで拾い、日本語**字幕**として低レイテンシで表示する。会議の原音声を聞きながら、手元の画面で文脈を理解する用途。**翻訳音声の再生は任意（既定オフ）**。会議音声を拾うため getUserMedia の音声処理（エコー除去/ノイズ抑制/自動ゲイン）は無効化する。ヘッドホン利用時はマイクが会議音声を拾えないため、将来的にシステム音声取込（getDisplayMedia 等）を検討。
- **UC-3 停止 / クリア**: 翻訳を Stop してマイクを解放し、画面の字幕を Clear する（保存しない）。
- **UC-4 セッション終了 / 離脱**: タブを閉じる / 再読み込みで WebRTC とマイクが確実に解放される。

非ユースケース（やらない）: 翻訳履歴閲覧、共有、複数ユーザー管理、双方向会話翻訳、日→英、音声合成での読み上げ（MVP では字幕表示のみ）。

## 2. MVP スコープ

- OAuth ログイン + 許可メール認可。
- `/translate` 画面（Start / Stop / Clear）。
- サーバーの client secret 発行 API（認証 + allowlist + レート制限）。
- ブラウザ WebRTC 接続 → `gpt-realtime-translate` で英→日翻訳。
- 部分テキスト（delta）を字幕としてリアルタイム表示。
- 本文の非保存 / 非ログ化。
- iPhone Safari と PC ブラウザでの動作。

## 3. 非 MVP スコープ（後回し）

- 翻訳履歴の保存・検索・エクスポート。
- DB 導入、ユーザー管理画面、設定の永続化。
- 双方向 / 多言語 / 音声読み上げ（TTS）。
- 外部分析・トラッキング・エラー監視 SaaS。
- PWA / ネイティブアプリ化、オフライン対応。
- 複数同時セッション、共有リンク。

## 4. 機能要件

- FR-1: 未認証ユーザーは `/translate` と全 API にアクセスできない（リダイレクト or 401）。
- FR-2: 認証済みでも `ALLOWED_EMAILS` 外は 403 相当で拒否（セッションを張らない）。
- FR-3: client secret 発行 API は短命トークンのみ返し、標準キーを返さない。
- FR-4: Start で WebRTC 接続を確立し、マイク音声を送信する。
- FR-5: 受信した日本語訳(`session.output_transcript.delta`)と英語原文(`session.input_transcript.delta`)を逐次・**併記**で字幕表示する（英語=小/淡色、日本語=大、最新行を強調）。
- FR-6: Stop でマイク（MediaStream トラック）と PeerConnection を解放する。
- FR-7: Clear で画面上の字幕を消す（メモリ上のみ、保存しない）。
- FR-8: ページ unload 時に接続とマイクを解放する。

## 5. 非機能要件

- NFR-1 レイテンシ: 体感で「話してから 1〜2 秒程度」で字幕が追従すること（ネットワーク依存。目標値）。
- NFR-2 軽量: 依存最小、初回ロード軽量、モバイルで安定動作。
- NFR-3 可用性: 個人利用前提。SLA 不要だが、接続失敗時に分かりやすく再接続できる。
- NFR-4 コスト: 翻訳は従量（per minute）。想定利用時間からの月額概算を README/docs で把握できる。
- NFR-5 保守性: ドキュメント駆動で、軽量 Agent が小さく安全に拡張できる。

## 6. セキュリティ要件

- SR-1: 標準 API キーをブラウザに出さない / `NEXT_PUBLIC_` に秘密を置かない。
- SR-2: 認証必須・許可メール認可。
- SR-3: client secret 発行はサーバーのみ・認証 + allowlist + レート制限。
- SR-4: HTTPS 前提、secure cookie、CSRF / CSP / CORS を `docs/security.md` 通りに設定。
- SR-5: 依存の脆弱性監査（`npm audit`）を CI / 手動で実施。

## 7. プライバシー要件

- PR-1: 音声・transcript・翻訳本文・会話内容を保存しない。
- PR-2: それらをログ / `console` / ブラウザストレージに残さない。
- PR-3: OpenAI へ送る内容がモデル学習に使われない前提の設定・契約を用いる（既定でも API データは学習に不使用。さらに ZDR / Modified Abuse Monitoring を `docs/privacy-data-handling.md` の手順で確認・申請）。
- PR-4: ユーザー識別子は平文メールでなくハッシュを Safety Identifier に使う。

## 8. 受け入れ条件（MVP 全体）

- AC-1: 許可メールでログインでき、許可外メールは拒否される（テストあり）。
- AC-2: 未認証で `/translate` / API にアクセスすると拒否される。
- AC-3: client secret 発行 API のレスポンスに標準キーが含まれない。
- AC-4: 英語を話すと日本語字幕がリアルタイム表示される（実機含む）。
- AC-5: Stop / Clear / タブ閉じでマイクと接続が解放される。
- AC-6: ネットワーク / ログ / ストレージのいずれにも本文が保存・出力されていないことを確認済み。
- AC-7: iPhone Safari で動作する。

## 9. 完了の定義（DoD）

- `docs/security.md` チェックリストの MVP 必須項目が ✅。
- `docs/privacy-data-handling.md` の保持方針が実装と一致。
- lint / typecheck / テスト green。秘密情報・本文の漏れなし。
