# docs/cost-estimation.md — 運用コスト試算

> 注意: 価格は 2026 年時点の調査値。**最新の OpenAI 料金ページで都度確認**すること。為替は仮定（1 USD = ¥155 と仮置き、要更新）。断定せず概算として扱う。

## 1. コスト構成要素

| 項目 | 課金 | MVP での扱い |
|---|---|---|
| OpenAI `gpt-realtime-translate`（英→日 翻訳） | **$0.034 / 分**（分課金） | 主コスト |
| OpenAI `gpt-realtime-whisper`（参考: 文字起こし） | $0.017 / 分 | MVP 未使用（translate のみ） |
| OpenAI `gpt-realtime-2`（参考: 汎用） | トークン課金 | MVP 未使用 |
| Vercel ホスティング | Hobby 無料 / Pro $20/月 | 個人利用は Hobby 想定 |
| Google OAuth | 無料 | 認証 |
| 独自ドメイン（任意） | 約 $10〜15 / 年 | 任意 |
| DB / 監視 SaaS / 分析 | — | **MVP で導入しない（$0）** |

> ⚠️ verify: translate の課金が「セッション分数」か「入力音声分のみ」か、字幕のみ利用時の課金挙動を最新ドキュメントで確認。本試算は「翻訳セッションの実時間（分）」課金と仮定。

> 補足（英語原文の併記）: 英語原文を表示するため入力文字起こし `gpt-realtime-whisper`（$0.017/分）を有効化している。translate と別課金なら**合計 ≒ $0.051/分**になり得る。英語併記が不要なら入力 transcription を外せば translate 分のみに削減可能（要・実請求での確認）。

## 2. 利用量別の月額試算（OpenAI translate のみ）

$0.034/分 = **$2.04/時間**。

| 利用シナリオ | 月間利用 | OpenAI 概算 | 円換算(¥155/$) |
|---|---|---|---|
| ごく軽い（合計 2 時間/月） | 120 分 | $4.08 | 約 ¥630 |
| 軽い（10 分/日 × 30） | 300 分 | $10.2 | 約 ¥1,580 |
| 標準（30 分/日 × 30） | 900 分 | $30.6 | 約 ¥4,740 |
| 多め（1 時間/日 × 30） | 1,800 分 | $61.2 | 約 ¥9,490 |
| 業務級（3 時間/日 × 20） | 3,600 分 | $122.4 | 約 ¥18,970 |

インフラ（Vercel Hobby + Google OAuth）が無料なら、**月額 ≒ OpenAI 利用分のみ**。

## 3. 想定される現実的なレンジ（個人利用）

- 標準的な使い方（毎日 20〜30 分程度）で **月 $10〜30（約 ¥1,500〜4,700）** が目安。
- ピーク月（長時間の会議視聴等）でも **$60〜120** に収まる想定。
- インフラは個人利用なら **$0**（Vercel Hobby）。Pro が必要になれば +$20/月。

## 4. コスト管理・超過防止策

1. **OpenAI 側の使用量上限 / 予算アラート**を設定（ダッシュボードで月間ハードリミット・通知）。MVP で監視 SaaS を入れない方針のため、ここで代替する。
2. client secret の **TTL を短く**（既定 120 秒）＋ レート制限で、放置・濫用による課金を抑止。
3. **Stop / unload で確実にセッション解放**（実装済み）。つけっぱなしによる課金を防ぐ。
4. 必要なら UI に**自動停止（無音・一定時間でセッション終了）** を将来追加（非 MVP）。
5. 利用後の請求は **OpenAI Usage ページ**で月次確認（本文は見ない・使用量のみ）。

## 5. 監視方法（本文を見ずにコストだけ把握）

- OpenAI ダッシュボードの Usage / Billing（分数・金額のメタデータのみ。会話本文は対象外）。
- Vercel の使用量メータ（帯域・関数実行）。
- これらは**本文を保持しない**ため、プライバシー方針と両立する。
