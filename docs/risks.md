# docs/risks.md — リスク一覧

各リスク: 内容 / 影響 / 発生可能性 / 対策 / 残余リスク / 検出方法 / 対応チケット。

## Critical

### R-C1 標準 API キー漏洩
- 内容: `OPENAI_API_KEY` がブラウザ/バンドル/ログ/コミットに露出。
- 影響: 不正利用・課金被害。 発生可能性: 中（実装ミスで起こり得る）。
- 対策: サーバー専用参照、`NEXT_PUBLIC_` 禁止、`.env` 非コミット、build 後 grep、レビュー。
- 残余: キー保管先の漏洩。ローテーション手順で緩和。
- 検出: バンドル/ログ grep、secret scanning。 対応: T2.1.x, T4.1, T5.1。

### R-C2 client secret 発行 API の認可欠落
- 内容: 未認証/許可外が発行 API を呼べる。
- 影響: 無断利用・課金。 発生可能性: 中。
- 対策: 認証+allowlist 二重照合+レート制限、テスト。
- 残余: セッション窃取。secure cookie/SameSite/短命で緩和。
- 検出: 認可テスト、ログの 401/403 監視。 対応: T2.1.1, T2.2.1, T1.3.1。

### R-C3 翻訳本文のログ/保存混入
- 内容: transcript/翻訳が log/console/storage/DB に残る。
- 影響: プライバシー要件違反。 発生可能性: 中（delta デバッグで起きやすい）。
- 対策: ログ正規化、本文出力禁止、storage 未使用、grep/レビュー。
- 残余: third-party SDK の暗黙ログ → MVP で外部 SDK を入れない。
- 検出: ログ grep、devtools storage 確認。 対応: T4.1, T4.2, T5.1。

## High

### R-H1 client secret 不正取得
- 内容: 短命トークンが窃取され有効期間内に悪用。
- 影響: 限定的な不正利用。 発生可能性: 低〜中。
- 対策: TTL 短縮(120s)、HTTPS、レート制限、Safety-Id。
- 残余: 有効期間内の悪用。TTL 最小化で緩和。 検出: 異常な発行頻度。 対応: T2.1.2, T2.2.1。

### R-H2 許可外ユーザー利用
- 内容: allowlist 漏れ/設定ミス。
- 影響: 無断利用。 発生可能性: 中。
- 対策: コールバック+API 二重照合、小文字化比較、テスト。
- 残余: allowlist 設定ミス。レビューで緩和。 検出: 認可テスト。 対応: T1.2.x。

### R-H3 ブラウザストレージへの保存
- 内容: 本文が localStorage 等に残る。
- 影響: 端末上に痕跡。 発生可能性: 低。
- 対策: storage 不使用方針、レビュー、devtools 確認。
- 残余: 将来機能で混入 → AGENTS.md 禁止で抑止。 検出: devtools。 対応: T3.3.1, T4.2。

### R-H4 API 事業者側のデータ保持
- 内容: ZDR 未承認だと abuse 監視で一時保持され得る。
- 影響: 本文がアプリ外で短期間保持され得る。 発生可能性: 中（既定挙動）。
- 対策: ZDR/Modified Abuse Monitoring 申請・承認、最新規約確認、断定回避の表現。
- 残余: 例外保持（CSAM 等）・対象外エンドポイント。 検出: OpenAI ダッシュボード/契約確認。 対応: T4.3。

## Medium

### R-M1 iPhone Safari 制約
- 内容: マイク権限/バックグラウンドでストリーム停止/secure context。
- 影響: 動作不良。 発生可能性: 中。
- 対策: ユーザー操作起点の getUserMedia、復帰再接続、HTTPS、権限導線。
- 残余: OS 仕様変更。 検出: 実機確認。 対応: T3.2.2, T5.3。

### R-M2 レイテンシ過大
- 内容: ネットワーク/設定で字幕が遅延。
- 影響: 体感低下。 発生可能性: 中。
- 対策: WebRTC 直結、translate モデル、遅延/精度トレードオフ設定の調整。
- 残余: 回線依存。 検出: 実測。 対応: T3.1.x。

### R-M3 コスト超過
- 内容: per-minute 課金の使いすぎ。
- 影響: 想定外課金。 発生可能性: 低〜中。
- 対策: TTL/セッション時間の把握、利用は個人のみ、概算を docs 化、必要なら上限アラート。
- 残余: monitoring SaaS を入れない方針との両立 → OpenAI 側の使用量確認で代替。 検出: OpenAI 使用量。 対応: README/docs。

### R-M4 Agent が勝手に方針変更
- 内容: 軽量 Agent がアーキ/依存/方針を独断変更。
- 影響: 制約逸脱。 発生可能性: 中。
- 対策: AGENTS.md 禁止事項、確認ゲート、チケット範囲限定、レビュー。
- 残余: 指示逸脱。 検出: 差分レビュー。 対応: 全チケット共通。

## Low

### R-L1 依存ライブラリ脆弱性
- 対策: `npm audit`、依存最小化、lockfile。 検出: audit/CI。 対応: T5.2。

### R-L2 Agent に秘密情報を渡す事故
- 内容: プロンプトに実キー/実ログを貼る。
- 対策: AGENTS.md 禁止、`.env.example` のみ共有、実データ不使用ルール。
- 残余: 運用者の手作業ミス。 検出: レビュー。 対応: 運用ルール。
